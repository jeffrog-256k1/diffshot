# Contributing

Keep Diffshot focused on reviewing two page versions with as little setup as possible. Start an issue before adding a new capture engine, hosted service, authentication, or CI workflow integration.

Use Node.js 22.12+ and `npm ci`. Run `npm test`, `npm run build`, `npx playwright install chromium`, `npm run test:browser`, and `npm run format:check` before submitting changes. Browser fixtures are entirely fictional; never commit a report from a private application.

Messages live in `src/i18n.mjs` in English, Korean, Simplified Chinese, Japanese, and Spanish order. Keep all five introductory READMEs consistent. JSON keys, options, and technical metadata remain language-independent.

Good first contributions include a reproducible rendering edge case, clearer error guidance, or a translation correction. Include a small local fixture. Do not add arbitrary URL fetching to the public demo, telemetry, external fonts, or automatic report uploads.

`npm run demo:capture` regenerates `assets/demo.json` from `examples/fixture.mjs`. Review it before committing. The static demo is generated by `npm run build`; local reports and test artifacts are ignored.
